# Stage 6.51 - BIG_MAP.SAV Czech / English mission compatibility

The retail English `COMMON.FS` is a strict tactical-mission subset of the Czech data set used for restoration testing:

- English: 95 tactical `Mxx_xx*.DEF` files.
- Czech: 136 tactical `Mxx_xx*.DEF` files.
- Czech-only: 41 mission DEFs.

`BIG_MAP.SAV` contains no explicit language/version marker, therefore save provenance cannot be identified reliably when the save only references missions shared by both releases. Compatibility is checked from the mission tokens stored in the save instead.

Import policy:

- Czech retail assets accept both English-compatible and Czech saves.
- English retail assets reject a `BIG_MAP.SAV` as soon as any territory references one of the known 41 Czech-only mission tokens.
- The rejection happens before strategic state is applied and tells the player to load the Czech game assets.
- A Czech save that currently references only missions common to both editions is accepted by English assets because it is content-compatible at that point; there is no reliable language bit in the save with which to distinguish it.
- Unknown / modded mission sets are not falsely labelled as retail English or Czech by the strict asset-set detector.

The known Czech-only set was generated by comparing the supplied Czech and English `COMMON.FS` archives, not inferred from mission numbering.
